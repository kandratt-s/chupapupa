# 📸 Система хранения файлов CHUPAPUPA

## Обзор

Реализована централизованная система хранения файлов для userStatistic и attendance сервисов с использованием общих Docker томов.

## 📁 Структура хранения

```
/shared/photos/
├── faces/           # Фотографии пользователей (userStatistic)
│   └── {user_id}.{ext}   # Формат: 123.jpg, 456.png
└── attendances/     # Файлы посещений (attendance)
    └── {attendance_id}.{ext}   # Формат: 789.pdf, 101.jpg
```

## 🏗️ Архитектура

### Docker конфигурация
- **Общий том**: `photos_data` смонтирован как `/shared/photos` во всех сервисах
- **Сервис инициализации**: `photos-volume` создает структуру папок при запуске
- **Безопасность**: Внутренние сервисы не имеют внешних портов, доступ только через Gateway

### Переменные окружения
```yaml
# UserStatistic сервис
PHOTOS_PATH=/shared/photos/faces

# Attendance сервис  
PHOTOS_PATH=/shared/photos/attendances

# Auth сервис (общий доступ)
PHOTOS_PATH=/shared/photos
```

## 📋 UserStatistic сервис

### Новый функционал
✅ **PhotoService** - управление фотографиями пользователей
✅ **API эндпоинты** для работы с фотографиями
✅ **Статические файлы** - доступ к фото через `/static/faces/`
✅ **Схемы данных** - добавлено поле `photo_url` в `UserResponse`

### API эндпоинты

#### Загрузка фотографии
```http
POST /users/me/photo
Content-Type: multipart/form-data

{
  "photo": <file>
}
```

#### Получение своей фотографии
```http
GET /users/me/photo
```

#### Получение фотографии любого пользователя
```http
GET /users/{user_id}/photo
```

#### Удаление фотографии
```http
DELETE /users/me/photo
```

### Поддерживаемые форматы
- JPG, PNG, GIF, BMP, WebP, TIFF

### Правила именования файлов
- **Формат**: `{user_id}.{расширение}`
- **Примеры**: `123.jpg`, `456.png`, `789.gif`

## 📋 Attendance сервис

### Обновленный функционал
✅ **PhotoService** - обновлен для использования общих томов
✅ **Поддержка PDF** - сохранение документов посещений
✅ **Статические файлы** - доступ через `/static/attendances/`
✅ **Интеграция** с общей файловой системой

### Поддерживаемые форматы
- **Изображения**: JPG, PNG, GIF, BMP, WebP, TIFF, SVG
- **Документы**: PDF

### Правила именования файлов
- **Формат**: `{attendance_id}.{расширение}`
- **Примеры**: `101.jpg`, `102.pdf`, `103.png`

## 🔗 Доступ к файлам

### Через отдельные сервисы
```bash
# UserStatistic - фотографии пользователей
http://localhost:8006/static/faces/{user_id}.{ext}

# Attendance - файлы посещений
http://localhost:8003/static/attendances/{attendance_id}.{ext}
```

### Через API Gateway (рекомендуется)
```bash
# Фотографии пользователей
http://localhost:8000/users/{user_id}/photo

# Файлы посещений (через проксирование)
http://localhost:8000/attendances/...
```

## 🛡️ Безопасность

### Валидация файлов
- ✅ Проверка MIME-типов
- ✅ Валидация структуры изображений (PIL)
- ✅ Ограничение размеров (настраивается)
- ✅ Фильтрация расширений файлов

### Права доступа
- **Фотографии пользователей**: пользователи могут загружать/удалять только свои фото
- **Просмотр фотографий**: доступен всем аутентифицированным пользователям
- **Файлы посещений**: только для зарегистрированных участников мероприятий

## 🔄 Интеграция с существующими сервисами

### UserResponse схема
```python
class UserResponse(UserBase):
    user_id: int
    created_at: datetime
    updated_at: datetime
    photo_url: str | None  # 🆕 Новое поле для URL фотографии
```

### Автоматическое добавление photo_url
Все API ответы автоматически включают `photo_url` для доступа к фотографии пользователя.
