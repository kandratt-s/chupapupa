# game_habbits

Вот структурированный план командного проекта с распределением задач между 3 участниками. Он охватывает все требования, демонстрацию, архитектуру и безопасность. 

📌 Общая цель проекта Создать сервис, решающий конкретную проблему (например, помощь студентам в планировании учёбы, автоматизация задач, сбор обратной связи и т.п.) с веб-интерфейсом и Telegram-ботом. Всё должно быть контейнеризировано и запускаться одной командой. 🧩 Структура проекта 

1. Архитектура компонентов Компонент Технологии Контейнер Связь с другими Веб-интерфейс FastAPI + Streamlit ✅ REST API к Worker, доступ к БД Telegram-бот Python + aiogram ✅ REST API к Worker Worker (обработка) Python ✅ Получает запросы от бота и веба База данных PostgreSQL / SQLite ✅ Хранит данные, доступна только изнутри Все компоненты запускаются через docker-compose up Внешний доступ: только веб и бот 
2. Связь между компонентами REST API — основной способ взаимодействия Альтернативы (если хотите получить +): gRPC — для высокой производительности Kafka — для асинхронной обработки (сложно, но круто) 
3. Безопасность Все креды — через .env, пример в README.md База данных не выставляется наружу Исключения обрабатываются: бот и веб не падают при ошибках Логирование без токенов и паролей SQL-инъекции исключены: используйте ORM (например, SQLAlchemy) 
4. Демонстрация проекта 🔧 Схема сервисов в Miro (или аналогичной диаграмме) 🎯 Презентация проблемы и целевой аудитории 📱 QR-код на Telegram-бота 🌐 Демонстрация работы веб-интерфейса 👥 Распределение задач по участникам 👨‍💻 Распределение задач по участникам 

- 🧑 Участник 1 — Backend & Worker Реализация нейросетевого движка или логики обработки Создание REST API для взаимодействия с ботом и вебом Обработка ошибок, логика, безопасность Документация API (Swagger / ReDoc) 
- 🧑 Участник 2 — Telegram-бот Разработка бота на aiogram Интеграция с API Worker Обработка сообщений, UX Генерация QR-кода Обработка исключений 
- 🧑 Участник 3 — Веб-интерфейс + Docker Интерфейс на Streamlit / FastAPI Интеграция с API Worker и БД Настройка Docker и docker-compose.yml Создание .env и README.md Сборка Miro-схемы
